# Mô hình 3D

Các mô hình trong thư mục này được tối ưu (bỏ vũ khí, bớt hoạt ảnh, gộp đồ vật) từ:

- **KayKit – Character Pack: Adventurers 1.0** — https://github.com/KayKit-Game-Assets/KayKit-Character-Pack-Adventures-1.0
- **KayKit – Restaurant Bits 1.0** — https://github.com/KayKit-Game-Assets/KayKit-Restaurant-Bits-1.0
- **KayKit – Furniture Bits 1.0** — https://github.com/KayKit-Game-Assets/KayKit-Furniture-Bits-1.0

Tác giả: Kay Lousberg (https://kaylousberg.com). Giấy phép **CC0 1.0** (dùng tự do, kể cả thương mại, không bắt buộc ghi công).

Tạo lại: xem hướng dẫn đầu file `scripts/build-models.mjs`, rồi chạy `node scripts/embed-models.mjs`.
